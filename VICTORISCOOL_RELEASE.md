# VictorIsCool 1.0.0 release build

This branch contains the VictorIsCool client and OSS server package merged from pull request #2.

Build targets:

- Windows x86_64 and ARM64
- Linux x86_64 and ARM64
- macOS x86_64 and Apple Silicon
- Android ARM64, ARMv7 and x86_64

The branch is intended for GitHub Actions artifact generation and release validation.
